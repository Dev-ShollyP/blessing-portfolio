# Blessing — AI Video Creator & Visual Storyteller Portfolio

A modern, high-performance, mobile-first portfolio website for **Blessing (AI Video Creator)**, showcasing end-to-end AI video productions, commercial spec advertisements, virtual influencer lifestyle vlogs, market shopping vlogs, and culinary storytelling from **Blessing Cooks**.

Inspired by the design architecture of [olushola-shotayo.vercel.app](https://olushola-shotayo.vercel.app/).

---

## 🎨 Color Theme Combo

- **Champion Blue**: `#151130` (Deep midnight indigo base tone)
- **Lavender Tonic**: `#C8BEFA` (Luminous lavender accent)

---

## 🌟 Key Features

1. **Mobile-First 9:16 Video Showcase**:
   - Optimized for modern short-form formats (YouTube Shorts, TikTok, Instagram Reels, mobile spec ads).
   - High-definition video posters with zero layout shift.
   - Interactive full-screen **Cinema Lightbox Modal** with HTML5 playback, video seeking, and full technical breakdown.

2. **6 Core Specializations & Accurate Video Projects**:
   - **AI Video Production**: *Cheesy Potato Balls* (Living room to kitchen multi-scene culinary continuity).
   - **AI Commercial & Advertisement**: *Product Spec Advertisement* (High-converting commercial concept).
   - **AI Lifestyle & Influencer**: *What I Eat in a Day* (Virtual influencer POV vlog routine).
   - **Short-Form Video & Editing**: *Breakfast Smoothie Recipe* (Healthy breakfast prep, blender assembly, voiceover & pacing).
   - **Social Media Video Content**: *Market Day Shopping* (Authentic local market vlog, street interaction & grocery shopping).
   - **AI-Powered Storytelling**: *Don't Turn Around* (2-minute suspense & narrative comedy short).

3. **Client Conversion & Communication**:
   - Direct click-to-chat integration for WhatsApp (**09011364204** / `+2349011364204`).
   - Interactive Project Brief / Inquiry form that formats details and launches WhatsApp directly.
   - Click-to-copy email action.
   - Direct link to YouTube channel: [`@Blessing_Cooks`](https://www.youtube.com/@Blessing_Cooks).

4. **Aesthetic & Technical Standards**:
   - Styled with the **Champion Blue (#151130)** & **Lavender Tonic (#C8BEFA)** palette.
   - Zero-FOUC **Dark / Light Mode** switcher with persistent user preference.
   - Uses official profile portrait (`profile photo.jpeg`).
   - Responsive design across mobile phones, tablets, laptops, and ultra-wide displays.
   - Fast loading with local HTTP Range request support for smooth MP4 scrubbing.

2. Start the lightweight streaming server:
   ```bash
   node server.js
   ```
3. Open your browser at:
   ```
   http://localhost:3000
   ```
